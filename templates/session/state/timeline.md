# Хронология — строго приватно

Сюда Amvera автоматически добавляет только значимые события игрового хода
по `timeline_events` от ChatGPT, сгруппированные по дате.

Формат:
## 02.05.2024
- [Краткий установленный факт, без выдуманного объяснения]

Не записывать бытовые действия без последствий, приватные догадки НПС,
повторные пересказы сцен. Время вписывать в текст факта, только если важно.
Полное содержание хода остаётся в журнале; аудит может уплотнять
хронологию без удаления событий.
