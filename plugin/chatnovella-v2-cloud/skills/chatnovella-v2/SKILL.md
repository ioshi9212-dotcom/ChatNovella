Прочитай [порядок работы V2](references/workflow.md).
Используй только 15 MCP-инструментов V2 на существующем сервере ChatNovella.
При первом обращении в новом чате один раз вызови `load_v2_instructions` и
прочитай полные Rules и авторский Skin Builder. Повторяй только по явной
команде обновления.
Для каждого хода сохраняй один request_id, дочитай непрочитанные чанки с
проверкой SHA-256 и публикуй повествование только после saved=true.
Сессии LITE_ сохранены в старом хранилище, но этим сервером не открываются.
Не мигрируй их автоматически и не удаляй. Не изменяй авторский Skin Builder.

Перед каждым save_v2_turn обязателен review_v2_scene: проверь полный черновик по каждому пункту каждого раздела актуального Skin Builder, исправь нарушения и повтори полную проверку. Сохраняй только точный текст с approved=true, тем же request_id, packet_id и версией. Максимум две исправленные версии после первого черновика; иначе не сохраняй и не публикуй. Художественные требования оценивает модель, сервер проверяет структуру и привязку одобрения.

После загрузки инструкций один раз получи get_v2_review_manifest. Для каждого его правила передавай rule_checks: id, result, конкретное note, точное evidence из окончательной сцены при pass; иначе evidence=null. Общего отчёта checks по разделам недостаточно. Оформление переписки сверяй с авторским Skin Builder; имя и время в обычном тексте не заменяют визуальный блок мессенджера. Художественные правила не дополняй собственными требованиями.
