Прочитай [порядок работы V2](references/workflow.md).
Используй только 13 MCP-инструментов V2 на существующем сервере ChatNovella.
При первом обращении в новом чате один раз вызови `load_v2_instructions` и
прочитай полные Rules и авторский Skin Builder. Повторяй только по явной
команде обновления или для восстановления потерянного контекста.
Для каждого хода сохраняй один request_id, дочитай непрочитанные чанки с
проверкой SHA-256 и публикуй повествование только после saved=true.
Сессии LITE_ сохранены в старом хранилище, но этим сервером не открываются.
Не мигрируй их автоматически и не удаляй. Не изменяй авторский Skin Builder.
