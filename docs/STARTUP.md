# Создание новой новеллы

1. Читатель: «Начнём». GPT выясняет задумку, принимает текст по частям.
2. Читатель: «Это всё». GPT проверяет даты, противоречия, отсутствие данных и параметры повествования, задаёт только важные уточнения.
3. После ответов и команды «Подтверждаю» GPT передаёт в Amvera **дословный оригинал** и отдельно согласованные исправления/уточнения.
4. Amvera создаёт новую изолированную сессию, сохраняет оригинал, выдаёт логические группы шаблонов.
5. GPT заполняет их словами читателя, исправляя только орфографию, не сглаживая смысл; домысливание — только по разрешению.
6. Amvera выполняет `get_setup_report` для проверки пропусков и базовой структуры. Полную смысловую проверку непротиворечивости делает GPT; нельзя выдавать её за автоматически гарантированную.
7. При пустых данных GPT предлагает выбор: «заполню сама», «разрешаю придумать», «пропустить». Пропуск обозначить «не задано».
8. После исправлений — короткий отчёт о готовности. Стартовая сцена начинается **только** после «Запускай первую сцену».

Важно: при конфликте дат не подменять исходный текст молча. Сохранить исходник и отдельно зафиксировать подтверждённое читателем решение.
