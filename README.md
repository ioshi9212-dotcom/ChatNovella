# ChatNovella

**ChatGPT — писатель. Amvera — сборщик, хранитель и проверяющий состояния.**

## Состояние проекта
Есть работающий в локальных тестах **MVP серверной логики**: независимые
сессии, версия состояния, выборочные анкеты НПС, чанки до 36 000 символов,
чистые текстовые файлы, история ходов и аудиты каждые 15/60 ходов.
Добавлена обёртка MCP (Streamable HTTP) и конфигурация для Amvera.
Публичный домен Amvera разрешён в проверке Host; MCP `initialize` передаёт
стартовую инструкцию плагина. Локальные транспортные тесты проверяют
инициализацию, список 12 инструментов и чтение без изменения сессий.

**18 ноября 2026: живой MCP на Amvera проверен.**
По адресу `https://chatnovella-yumikofv.waw0.amvera.tech/mcp` успешно выполнены
`initialize`, `tools/list` (12 инструментов) и чтение `list_novella_sessions`
через MCP Python SDK. Стартовая инструкция присутствует в `initialize`.
Создан приватный обычный плагин
[ChatNovella](https://chatgpt.com/plugins/plugins_6afd370d79cc81918ce81a61aedfd13b).
Подключение и игровой ход внутри ChatGPT пока не подтверждены. Панель и логи
Amvera не проверены: вход был отклонён.

Позднее 18 ноября создано отдельное веб-подключение
[ChatNovella Amvera](https://chatgpt.com/plugins/plugin_asdk_app_6afd39aad9808191bf94bb81e3c2f394)
через добавление пользовательского MCP-сервера. В версию 1.0.1 этого плагина
добавлены инструкция ChatNovella и полный порядок работы; исходная привязка
приложения сохранена. Снимки пользователя подтверждают создание подключения
в браузере; игровой вызов из нового чата ещё предстоит проверить.
Исходники этой версии находятся в `plugin/chatnovella-amvera/`.
По умолчанию токен не требуется; при публичном URL API будет доступен без авторизации.

## Коротко о принципах
- Каждая новелла изолирована: `/data/chatnovella/sessions/<session_id>/`.
- Оригинал читателя сохраняется **1:1** и не читается на каждом ходу.
- Текущие состояния — простые `.md`. JSON только для сервера/обмена.
- Приватные знания принадлежат конкретному НПС и не передаются автоматически.
- Сцена сохраняет физическую непрерывность: тело, позу, касания, одежду,
  бельё, обувь, предметы, наблюдение и подслушивание.
- По телефону загружаются голос, характер, знания и отношения;
  наблюдателю — способности, характер, знания и отношения;
  при физическом присутствии — вся анкета.
- Все общие файлы приходят **полностью**, при необходимости несколькими
  чанками по 36 000 **Unicode-символов**. Предельный контекст GPT остаётся отдельным ограничением.
- GPT отвечает за сюжет и аудит смысла. Сервер сейчас проверяет структуру,
  версии, дубли ID и границы числовых показателей. Это не «автоцензор».

## Структура репозитория
- `chatnovella/store.py` — хранение сессий, пакеты, версии, журнал и аудиты.
- `chatnovella/mcp_server.py` — MCP-инструменты с необязательной Bearer-авторизацией.
- `templates/session/` и `templates/character/` — простые анкеты и состояния.
- `rules/` — технические Rules, отдельно от состояния сессий.
- `runtimes/` — отдельные модули режиссуры, NPC, POV и непрерывности.
- `skin/` — только оформление готового повествования.
- При **каждом** вызове `prepare_novella_turn` Amvera подгружает Rules, все runtimes и Skin Builder **перед** файлами состояния, полностью и без дублирования в `/data`. Большие пакеты передаются чанками по 36 000 символов.
- `tests/` — локальные тесты.
- `amvera.yaml` — конфигурация запуска на Amvera.

## Инструкции

**Живые сессии не сохранять в GitHub.** Они остаются на диске Amvera `/data`.
