# Knowledge runtime — приватная память

`knowledge.md` каждого НПС — только его информация. Передавать знание другому только после реального события (рассказ, подслушивание, наблюдение, сообщение, документ, способность с условиями). Различать «знает», «предполагает», «ошибочно считает». Не вводить абсурдный запрет на бытовые фразы, догадки, совпадения, ложь или блеф. Но не превращать скрытый конкретный факт в уверенное знание без причины. Сайлас, наблюдающий через отражение, получает только то, что его способность позволяет видеть/слышать.
